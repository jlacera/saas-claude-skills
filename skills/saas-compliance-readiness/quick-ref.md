# 📑 Compliance Readiness — Quick Reference

## 🚨 Top 3
1. **Evidence, not intention.** A control without a verifiable artifact is a BLOCKING GAP, never "partially covered".
2. **Pick the framework the buyer actually asks for.** Spanish/EU SaaS order: GDPR → ISO 27001 → ENS (public sector) → NIS2 (if in scope) → SOC 2 only when a contract demands it.
3. **Never call a system "compliant".** The deliverable is audit readiness; the auditor issues the verdict.

---

## 📋 Framework priority (EU market)

| Framework | Matters when | Entry cost |
|---|---|---|
| GDPR | Always | Documentation |
| ENS | Selling to Spanish public sector | Accredited certification |
| ISO 27001 | European corporate buyer asks for it | External audit, annual cycle |
| NIS2 | Mandatory by sector and size | Self-assessment + board liability |
| SOC 2 Type II | US buyer or US-owned subsidiary | Observation window + CPA auditor |

## ✅ Readiness matrix (10 controls)

Access control · Encryption at rest and in transit · Immutable audit log · Incident response plan with a rehearsed drill · Vendor inventory with signed DPAs · Change management · **Backups with an executed restore drill** · Legal basis and data subject rights · BC/DR with measured RTO/RPO · Training and board accountability.

---

## 🔁 Build-vs-buy audit

1. Inventory subscriptions → flag any using **<40% of features** as BUILD CANDIDATE
2. Scope in modules → **>5 modules = HIGH COMPLEXITY**, keep the subscription
3. Operator maturity → no track record, start with the simplest candidate
4. Savings vs build **and ongoing maintenance** cost
5. Written acceptance test **before** cancelling anything
